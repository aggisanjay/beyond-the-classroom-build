## Security and Row Level Security

Enable RLS.

The required security model is:

- Anonymous visitors may submit a valid enquiry through a controlled server-side endpoint.
- Anonymous visitors must not have unrestricted SELECT, UPDATE, or DELETE access to enquiries.
- Only authenticated, authorized administrators may view enquiry records.
- Only explicitly authorized administrators may perform any administrative mutations.
- Do not treat every authenticated user as an administrator.
- Restrict access using a trusted administrator allowlist or a properly secured administrator-role mechanism.
- Never trust an email, role, or administrator flag supplied by the browser.

Use a secure server-side database access pattern with validation and appropriate rate limiting or abuse protection.

If using a Supabase service-role key, keep it strictly on the server, never expose it in a Client Component, and perform explicit authorization checks before administrative operations.

Document how to apply the SQL migration and configure the required policies.
